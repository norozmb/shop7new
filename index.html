shop7new is a PHP application

This repository is hosted on GitHub Pages, which only supports static sites.

To run the full website, you need a PHP-capable host or local PHP server.

Use one of these options:

  • Local: run a PHP server and open index.php
  • Host: deploy to a PHP host such as Hostinger, Bluehost, or Render
